# Аудио в текст

WPF-приложение для распознавания речи: загрузите аудиофайл или запишите голос с микрофона, отправьте его в сервис распознавания и получите текст.

## Возможности

- **Два источника аудио**
  - файл: выбор через диалог или перетаскивание в окно (WAV, MP3, M4A, AAC, OGG, FLAC, WMA);
  - микрофон: выбор устройства записи, запись в WAV (PCM 16 бит, моно, 44,1 кГц), таймер и индикатор уровня сигнала.
- **Распознавание по кнопке** — запрос отправляется вручную, без автозапуска после записи.
- **Результат** — текст, состояние обработки, счётчики слов и символов, копирование в буфер обмена и сохранение в `.txt`.
- **История за сессию** — до 50 распознаваний; выбор записи показывает её текст.
- **Асинхронная работа** — сетевые запросы и сохранение записи выполняются вне потока интерфейса, окно не подвисает.
- Понятные сообщения об ошибках: недоступный сервис, таймаут, ошибка обработки на сервере.

## Требования

- Windows 10/11
- [.NET SDK 10.0](https://dotnet.microsoft.com/download) (проект нацелен на `net10.0-windows`)
- Микрофон — для записи с устройства

## Сборка и запуск

```powershell
# из корня репозитория
dotnet build SpeechToText.slnx

# запуск
dotnet run --project SpeechToText
```

Готовый исполняемый файл:

```
SpeechToText\bin\Debug\net10.0-windows\SpeechToText.exe
```

## Настройка

Параметры сервиса задаются в `SpeechToText\appsettings.json` (копируется рядом с `.exe` при сборке):

```json
{
  "Api": {
    "BaseUrl": "http://192.168.4.38:8800/",
    "FileFieldName": "file"
  }
}
```

| Параметр        | Описание                                                                 |
|-----------------|--------------------------------------------------------------------------|
| `BaseUrl`       | Адрес сервиса распознавания. Запрос идёт на `POST {BaseUrl}api/Audio`.    |
| `FileFieldName` | Имя поля с файлом в `multipart/form-data` (по умолчанию `file`).          |

Файл настроек можно менять прямо рядом с `.exe` — пересборка не требуется.

## Использование

1. Выберите источник: **Файл** или **Микрофон**.
2. Для файла — перетащите его в окно или нажмите на зону выбора.
3. Для микрофона — выберите устройство и нажмите круглую кнопку записи; повторное нажатие останавливает запись и сохраняет WAV.
4. Нажмите **Распознать**.
5. Результат можно скопировать, сохранить в `.txt` или открыть из истории.

## Где хранятся записи

Записи с микрофона сохраняются в подпапку `audio` рядом с исполняемым файлом:

```
<папка приложения>\audio\recording_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.wav
```

Папка создаётся автоматически. Записи **не удаляются автоматически** — ни при новой записи, ни при выходе, ни при следующем запуске. Удалить текущую запись можно кнопкой **«Удалить»** рядом с её именем.

## API

Приложение отправляет аудиофайл в `POST /api/Audio` как `multipart/form-data` и ожидает JSON:

```json
{
  "text": "распознанный текст",
  "state": "Success"
}
```

Ответ с пустым `text` или состоянием `Error` считается ошибкой распознавания. Спецификация — в `v1.json`.

## Архитектура

MVVM на [`CommunityToolkit.Mvvm`](https://learn.microsoft.com/dotnet/communitytoolkit/mvvm/), запись через [`NAudio`](https://github.com/naudio/NAudio). Без DI-контейнера: зависимости собираются в `App.xaml.cs`.

```
SpeechToText/
├── App.xaml / App.xaml.cs        # запуск, сборка зависимостей, освобождение ресурсов
├── MainWindow.xaml(.cs)          # интерфейс, обработка drag & drop
├── ViewModels/
│   └── MainViewModel.cs          # состояние формы, команды, история
├── Models/                       # настройки API, результат, история, устройства, режим ввода
├── Services/
│   ├── HttpAudioRecognitionService.cs   # HTTP-клиент распознавания
│   ├── AudioRecorderService.cs          # запись с микрофона (NAudio)
│   ├── DialogService.cs                 # диалоги выбора и сохранения файла
│   └── ClipboardService.cs              # буфер обмена
├── Infrastructure/
│   ├── AudioFormats.cs           # поддерживаемые форматы, MIME-типы, размеры
│   └── RecordingStorage.cs       # путь и имя нового WAV-файла
├── Converters/                   # конвертеры для привязок
├── Themes/Styles.xaml            # стили и палитра
└── appsettings.json              # адрес сервиса и имя поля файла
```

## Диагностика

- **«Не удалось подключиться к сервису распознавания…»** — проверьте `BaseUrl`, доступность хоста и что сервис запущен.
- **«Сервис вернул ошибку 500…»** — сервис принял запрос, но не смог обработать аудио; смотрите его журнал.
- **«Сервис не вернул текст распознавания…»** — проверьте формат файла и имя поля `FileFieldName`.
- **Микрофон не найден** — подключите устройство и нажмите **«Обновить»**; убедитесь, что оно не занято другим приложением.
